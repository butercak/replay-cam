# 回放相機（手機版 Replay Buffer）

用法跟 OBS 的回放緩衝一樣：相機開著時會一直在背景錄，但只保留**最近 X 分鐘**。打完一首覺得不錯，按下紅色按鈕，剛剛那 X 分鐘就會存成 MP4。

這是網頁型 App（PWA），iPhone 和 Android 共用同一份檔案，不需要上架，也不用開發者帳號。

## 1. 放上網路（只要做一次）

相機只能在 **https** 網址下使用，所以要把這個資料夾放到免費的網頁空間。推薦 GitHub Pages：

1. 註冊／登入 GitHub，建立一個新的 repository（例如 `replay-cam`），設為 Public。
2. 在 repo 頁面點 **Add file → Upload files**，把這個資料夾**裡面的所有檔案**（包含 `icons` 資料夾）拖進去，然後按 Commit。
3. 到 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/replay-cam/`。

也可以用 Netlify 或 Cloudflare Pages 這類服務，直接拖整個資料夾上去就能部署。

## 2. 裝到手機

- **iPhone（Safari）**：打開網址 → 下方「分享」按鈕 → **加入主畫面**。
- **Android（Chrome）**：打開網址 → 右上角 ⋮ → **安裝應用程式**（或「加到主畫面」）。

之後從主畫面的圖示打開，就會是全螢幕。第一次使用時要允許相機和麥克風權限。

## 3. 使用

- 按「開啟相機」後，左上角會顯示「回放 1:23 / 2:00」，代表目前已經緩衝了多少。
- 按紅色按鈕就會保存，保存期間錄影不會中斷。
- 右上角的影片圖示可以看保存好的影片，按 **存到相簿／分享** 選「儲存影片」就會存進相簿。
  ⚠️ 影片只暫存在 App 裡，關掉 App 就會消失，記得要存出來。
- 如果有藍牙鍵盤或「鍵盤型」的藍牙自拍遙控器，按空白鍵或 Enter 也能保存。只送音量鍵訊號的遙控器在網頁裡收不到，所以不能用。

## 4. 設定建議（音遊手元）

| 項目 | 建議 |
|---|---|
| 回放長度 | 一首歌通常 2～3 分鐘，設 3 分鐘左右 |
| 解析度／幀率 | 1080p / 60fps（手機撐不住就改 30fps） |
| 畫質 | 12 Mbps；手指動作很快，太低會糊 |
| 原音收音 | **開**（關掉降噪和自動增益，才不會把遊戲音樂壓掉） |
| 音畫偏移 | 先在鏡頭前拍一下手，存下來看看，聲音比畫面早就填正數 |

設定頁會顯示預估的記憶體用量。iPhone 上如果超過大約 400～500 MB，系統可能會直接把 App 關掉，所以要錄很長的話請降低畫質。

## 5. 限制

- 錄影時 App 一定要在前景：鎖定螢幕或切到別的 App，相機就會被系統關掉。App 會自動讓螢幕保持常亮。
- 需要 iOS 16.4 以上，或比較新的 Android Chrome。
- 較舊的 iPhone 如果不支援聲音編碼，聲音會自動另外存成一個 WAV 檔，需要在剪輯軟體裡和影片合併。
- 旋轉手機（畫面從直的變橫的）會讓緩衝重新開始，錄的時候建議鎖定螢幕方向。

## 檔案

- `index.html`、`app.js`：主程式
- `audio-tap.js`：收音（AudioWorklet）
- `mp4-muxer.js`：MP4 封裝函式庫（MIT 授權，見 `mp4-muxer.LICENSE.txt`）
- `sw.js`、`manifest.webmanifest`、`icons/`：讓它可以安裝、離線開啟

在電腦上測試：在這個資料夾執行 `python -m http.server 8765`，再打開 `http://localhost:8765/?demo=1`，就會用假的相機畫面。
